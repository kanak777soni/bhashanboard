# 07 — Design Language

> **The brief:** modern, rich, unique — and it must not look like an AI-generated website.

That last constraint is the useful one, because "AI-generated" is not a vibe. It is a **specific, enumerable set of defaults**. Avoid them deliberately and the problem is solved.

## 7.1 What "AI-generated website" actually means

Every one of these is a default that a model reaches for when it has no opinion. Together they are the look.

| # | The tell | Why it happens |
|---|---|---|
| 1 | **Tailwind default palette** — `slate-900`, `indigo-600`, `gray-50` | Ships with the framework |
| 2 | **Purple→pink or blue→cyan gradients**, blurred gradient "orbs" behind the hero | The 2021 SaaS template look, now permanent |
| 3 | **Inter / Poppins / Montserrat**, one family, one weight, no contrast | Safe defaults |
| 4 | **`rounded-2xl` cards + soft `box-shadow` floating on light grey**, in a 3-column grid | The single most common AI layout |
| 5 | **Lucide/Heroicons line icon in a coloured circle** atop every card | Icon libraries are one import away |
| 6 | **Centred hero:** huge headline, grey subheading, one filled + one outline button | Template muscle memory |
| 7 | **Emoji as decoration** in headings and buttons | Free "personality" |
| 8 | **Glassmorphism**, `backdrop-blur`, translucent nav | Trend residue |
| 9 | **Perfectly even spacing everywhere** — one rhythm, no density variation | No editorial judgment |
| 10 | **`max-w-7xl mx-auto` on everything** — the whole site is one centred column | Path of least resistance |
| 11 | **Stack of full-viewport centred sections**, each with an eyebrow + heading + body | The "landing page" schema |
| 12 | **Fade-up-on-scroll on every element** | One library, applied globally |
| 13 | **Dark mode = the same layout with `bg-gray-900`** | Token swap, no redesign |
| 14 | **Emptiness.** Airy, low-information, nothing dense anywhere | Density requires real content and real decisions |

**#14 is the deepest one.** AI-generated sites are *empty* because emptiness is safe. The single strongest signal that a human built something is **information density handled well** — a page that is packed and still legible could not have been generated by someone with nothing to say.

Which is extremely convenient, because **this product is a ranking table.** Density is native to it.

## 7.2 The thesis

> ### The Bhashan Board should look like *Wisden Cricketers' Almanack* redesigned by a central bank.

Dense, typographic, ruled, tabular. Utterly, humourlessly serious about statistics that do not deserve it. Gold foil and wax seals applied to nonsense with a completely straight face.

Nobody's default reaches for this. It is unmistakably deliberate, it is impossible to confuse with a SaaS template, and it *is* the joke — the visual system and the comedic thesis are the same thing (`01-concept.md` §1.3, Deadpan Prestige).

### Reference set — physical objects, not websites

Do not moodboard from Dribbble or other sites; that is how you converge on the template look. Moodboard from **printed matter**:

- **Share certificates and banknotes** — guilloché engraving, serial numbers, foil, watermarks, "This is to certify that…"
- **Wisden Almanack** and newspaper sports pages — league tables, form guides, dense stat blocks in serif
- **Nobel diplomas, degree certificates, Oscar ballots** — ceremony rendered in ink
- **Central bank annual reports** — sober, rule-based, typographic authority
- **Indian government letterhead and gazette notifications** — the Ashoka-lion register of officialdom, seals, reference numbers, "No. F.12-3/2026"
- **Cricket scorecards** — the most beautiful dense data layout in the subcontinent
- **Vintage stock ticker boards and Wall Street tape**

## 7.3 Type

Typographic contrast is the cheapest way to look designed rather than generated. Four roles, four distinct voices.

| Role | Face | Why |
|---|---|---|
| **Display** — masthead, tier names, ceremony | **Libre Caslon Display** or **Newsreader** (both free) | High-contrast serif with real character. **Not Playfair** — it's the Inter of serifs now. |
| **Body / prose / transcripts** | **Source Serif 4** or **Newsreader** | Printed, readable, warm. Serif body copy is itself an anti-default. |
| **Labels / UI / nav** | **Archivo** or **Archivo Condensed**, ALL CAPS, `letter-spacing: 0.12em` | Condensed grotesque in spaced caps reads *institutional*. Underused. |
| **Numerals / ratings / ledgers** | **IBM Plex Mono** — tabular figures always | Ratings, ranks, GP, dates. Every number in a column must align. |
| **Devanagari** | **Tiro Devanagari Hindi** | Purpose-designed to sit beside Latin serifs. See §7.9 — do not skip this. |

**Rules:**
- **Big jumps.** Masthead 64px, section head 28px, body 17px, label 11px. Timid 32/24/18 scales read generated.
- **Old-style figures in prose, lining tabular figures in tables.** Two different numeral styles on one site is a craft signal almost nobody bothers with.
- **Small caps** for honorifics and conferred titles. Real small caps, not `text-transform`.
- **Hanging punctuation** on pull-quotes.
- Body measure **62–70 characters**. Transcripts get two columns.

## 7.4 Colour

Not a framework palette. A specific, slightly uncomfortable one.

```
--ink        #12100E   near-black, warm — never #000, never slate
--paper      #F4EFE6   aged cream — never #FFF, never gray-50
--paper-deep #E8E0D2   secondary surfaces
--rule       #12100E @ 15%   hairlines
--foil       #B08D3F   muted gold, not neon
--vermilion  #C4341F   the one aggressive accent — movement, alerts, corrections
--seal       #1F4D3D   committee green, for RATIFIED stamps
```

**One accent only.** `--vermilion` earns its loudness by being the only loud thing. It reads as Indian print red (sindoor, gazette stamps, exam-paper correction ink) without being nationalist-coded.

### Tier metals

Tiers must feel like **materials**, not swatches. No rainbow gradients.

| Tier | Treatment |
|---|---|
| 🪵 Participation | `#7A7266` matte, flat, no effect — deliberately sad |
| 🥉 Bronze | `#8C6239` with a faint vertical brushed gradient |
| 🥈 Silver | `#9AA0A6`, one hard specular highlight line |
| 🥇 Gold | `#B08D3F` + letterpress emboss + fine engraved rim |
| 💎 Diamond | Cold `#CFE3EA`, hard-edged facets, **one** slow specular sweep |
| 👑 Kohinoor | Deep imperial `#2B1B4A` ground, foil rim, wax seal, serial number |

### Dark mode = **The Night Edition**

Not `bg-gray-900`. Invert to an ink ground with paper-cream text, foil unchanged, vermilion desaturated one step. It should read like a **letterpress print in reverse** — and call it the Night Edition in the UI, because naming it is funnier and signals intent.

## 7.5 Materials & texture

This is where the site stops looking like a website. Four materials, all cheap to implement, all SVG/CSS:

**1. Guilloché** — the engraved spirograph pattern on banknotes and share certificates. Generate with SVG (layered `<path>` sine curves or a `feTurbulence` displacement). **This single element will make the site look like nothing else on the web.** Use it as: the border of statement certificates, the ground of Kohinoor cards, a watermark behind the masthead.

**2. Paper grain** — `feTurbulence` SVG filter at ~3% opacity over `--paper`. Invisible individually, transformative in aggregate. Kills the flat-digital feel instantly.

**3. Letterpress emboss** — headings get `text-shadow: 0 1px 0 rgba(255,255,255,.5), 0 -1px 0 rgba(0,0,0,.12)`. Text looks pressed *into* the paper.

**4. Rubber stamps** — source tiers, `RATIFIED`, `PROVISIONAL`, `UNDER REVIEW`, `WITHDRAWN`. Rotated 3–7°, slightly ink-bled edges, partially overlapping content. Hand-drawn SVG, never a font.

Plus: **wax seals** for Kohinoor rulings, **serial numbers** on every statement (`ENTRY No. 00417`), and **foil sheen** — a single slow gradient sweep, restricted to Diamond and Kohinoor only.

## 7.6 Layout laws

Hard bans. Each one directly kills a tell from §7.1.

| ❌ Banned | ✅ Instead |
|---|---|
| `box-shadow` on cards | **Hairline rules.** 1px `--rule`. Print has no drop shadows. |
| Border radius > 2px | Sharp corners. Certificates have corners. |
| Centred hero section | **A masthead.** Nameplate, tagline, edition number, date — then straight into content. |
| One centred `max-w-7xl` column | **Asymmetric 12-col editorial grid.** Main column 7, rail 3, margin 2 — and vary it per page. |
| Uniform vertical rhythm | **Density variation.** Tables `line-height: 1.2`; prose `1.65`. The contrast is the design. |
| Icon-in-circle atop cards | Custom engraved glyphs, inline, at text size |
| Emoji in chrome | Drawn SVG medals. Emoji only in user-generated content. |
| Gradient backgrounds | Paper, ink, guilloché |
| Full-viewport sections | Content-height sections. Let the fold fall wherever. |

### 🚫 No hero section on the homepage

The boldest call here, and the most important. **You land directly in the standings table.**

A masthead does the explaining, exactly as a newspaper nameplate does:

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   THE BHASHAN BOARD
   An archive of public wisdom. Independently ranked.
   EDITION CDXVII · 26 JULY 2026 · 1,847 ENTRIES ON RECORD
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   PARITY  ▓▓▓▓▓▓▓▓░░  BJP 31% · INC 29% · REGIONAL 33% · OTHER 7%
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

Then the table. No "Welcome to". No two buttons. No gradient blob.

Landing in dense, live data reads as **a real institution with real content**. A hero section reads as a landing page for a product that doesn't exist yet. Every scoreboard, exchange and almanack on earth works this way.

## 7.7 Motion doctrine

> **Stillness by default. Two moments of theatre.**

AI-generated sites animate everything on scroll. The most distinctive choice available is **restraint** — a site that sits perfectly still, like print, and then detonates exactly twice.

**No** scroll-triggered fades. **No** parallax. **No** animated counters. **No** hover-lift on cards.

**Yes**, in exactly two places:

1. **The stamp** *(duel vote)* — choose a clip and an ink stamp thuds down onto it: 120ms scale-in from 1.6×, 3° rotation, a hard settle, faint ink bleed. Tactile, instant, satisfying. This is the sound-and-feel of the whole product.
2. **The ceremony** *(promotion to Diamond / Kohinoor)* — full-screen takeover. Guilloché draws itself in, foil sweeps across, wax seal presses down with a slight squash, **ticker-tape paper confetti** (not coloured particles). ~2.5s. Earned, rare, and the only place the site raises its voice.

Everything else: `transition: 120ms ease-out` on colour and border only. Honour `prefers-reduced-motion` on both moments.

## 7.8 Iconography

**No icon library.** Lucide and Heroicons are instantly recognisable and are tell #5.

Draw **12 SVGs by hand** and reuse them everywhere:

`medal-bronze` · `medal-silver` · `medal-gold` · `medal-diamond` · `medal-kohinoor` · `wax-seal` · `gavel` · `quill` · `arrow-up` / `arrow-down` (hairline, engraved) · `stamp-frame` · `laurel`

Engraved line-art style — thin strokes, cross-hatching, no fills, no rounded caps. Twelve hand-made glyphs beat a 1,400-icon library for distinctiveness, and it's an afternoon of work.

## 7.9 Devanagari & multilingual typography

**Everybody forgets this, and on this site it is unforgivable** — a large share of your content is Hindi, Tamil, Telugu, Bengali, Marathi.

- Pair **Tiro Devanagari Hindi** with the Latin serif. Designed to match Latin text faces in colour and weight; the two will sit together properly instead of clashing.
- **Devanagari needs more line-height than Latin** — matras sit above and below the baseline. Set `line-height: 1.8` for Devanagari blocks vs `1.65` Latin. Getting this right is invisible to most users and screams craft to Indian ones.
- Devanagari has **no capital letters**, so ALL-CAPS labels break. Use weight and letterspacing for emphasis in Indic scripts, never case.
- Set `font-feature-settings` per script; don't apply Latin small-caps to Indic.
- **Bilingual transcripts as facing pages** — original left, English right, like a scholarly parallel-text edition. Beautiful, apt, and nobody else does it.

## 7.11 Implementation notes

- **Next.js App Router**, server components. SSR is non-negotiable (SEO + OG cards).
- **Do not use Tailwind's default theme.** If you use Tailwind, delete the entire default palette, spacing and radius scales and define your own tokens. **The AI look comes from default tokens, not from Tailwind itself.** Plain CSS Modules with custom properties is honestly the cleaner path here and I'd lean that way.
- **`next/font`, self-hosted.** No Google Fonts CDN — it's a render-blocking third party and a privacy issue under DPDP.
- **SVG for everything decorative** — guilloché, seals, medals, stamps. Inline the small ones, sprite the rest.
- **View Transitions API** for page navigation. Cheap, and it makes a multi-page site feel crafted rather than clunky.
- **Build the tokens file first**, before any page. Colour, type scale, rules, spacing. Every "make it look AI" mistake traces back to a component inventing its own values.

## 7.12 The one-line test

Before shipping any screen, ask:

> **Could this have been the fourth result in a template gallery?**

If yes, it needs more density, more typographic contrast, fewer shadows, and a rule where a card border is.
